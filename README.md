# Minimal60: A 60% customized keyboard with separated spacebar

This keyboard is inspired by Neson Design Keyboards, and GMK keycaps "Minimal".

## Case

The original [step file](./case/Minimal60.step) comes with no decoration. Please, feel free to make your own modification. You may find some useful [resources](./resources/) here.

## PCB 

The PCB uses Atmega32u4 and FPC connector. You can find the UDB with FPC connector in my another repository: [UDB-C-FPC](https://github.com/dianmo42/UDB-C-FPC).
